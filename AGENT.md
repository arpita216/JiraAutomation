# Agent Instructions

This repository uses a set of defined skills for common tasks.

## Project Context
- **Jira Project**: [GitJiraAutomation (GJA)](https://arpitas.atlassian.net/browse/GJA)
- **Active Epics**:
    - `GJA-1`: [Core] Foundation and Core Engine Implementation
    - `GJA-2`: [Auto] Workflow Automation and Trigger Systems

## Custom Skills
- [Commit Skill](.agents/skills/COMMIT.md): Standardized process for branch creation and commit messaging.
- [PR Skill](.agents/skills/PR.md): Templates and guidelines for creating Pull Requests.
- [JIRA Skill](.agents/skills/JIRA.md): Guidelines and templates for creating Jira tickets.
