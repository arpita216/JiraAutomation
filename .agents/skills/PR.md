# Pull Request Skill

Follow these instructions whenever asked to create a Pull Request (PR).

## PR Title
Format: `{type}({jira-ticket-id}): {PR-title}`

---

## PR Body Templates

Choose the appropriate template based on the ticket type.

### 1. Story / Task Ticket
```markdown
# Description
## Requirement

## Implementation

Author:

Jira ticket:
```

### 2. Bug Ticket
```markdown
# Description
## Issue

## Rootcause

## Fix

## Implementation

Author:

Jira ticket:
```
